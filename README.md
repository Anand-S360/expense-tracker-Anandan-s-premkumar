# Expense Tracker

A simple and beginner‑friendly **Expense Tracker** built with **HTML, CSS, and JavaScript**.  
This project helps you manage your income and expenses, track your balance, and filter transactions by type or category.  
All data is stored in **localStorage**, so your records persist even after refreshing the page.

---

## Features
- Add transactions with:
  - Type (Income / Expense)
  - Amount
  - Category
  - Date
  - Description
- View summary:
  - Total Income
  - Total Expense
  - Balance
- Filter transactions:
  - By type (Income / Expense / All)
  - By category keyword
- Delete transactions
- Data persistence using **localStorage**

---
## How to Use the Expense Tracker

1. **Add a Transaction**
   - Select whether it’s **Income** or **Expense**.
   - Enter the **amount** (e.g., ₹500).
   - Type a **category** (e.g., Food, Salary, Travel).
   - Pick a **date**.
   - Write a short **description** (e.g., “Dinner at restaurant”).
   - Click **Add Transaction** to save it.

2. **View Your Summary**
   - The summary section at the top updates automatically:
     - **Total Income**
     - **Total Expense**
     - **Balance** (Income – Expense)

3. **Filter Transactions**
   - Use the dropdown to show only **Income**, **Expense**, or **All**.
   - Type a keyword in the category filter box (e.g., “Food”) to narrow down results.

4. **Delete a Transaction**
   - Each transaction in the list has a **Delete** button.
   - Click it to remove that entry permanently.

5. **Data Persistence**
   - All transactions are saved in your browser’s **localStorage**.
   - Your data remains even after refreshing or reopening the page.
